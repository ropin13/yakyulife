YaKyoLife 離線生涯擴充版 v0.22.0

本版修正「完整 JSON 匯出檔案異常偏小」問題。

主要修正
1. 存檔格式升級為 saveSchema 3。
2. 年度對話同時保存完整 HTML 與逐區塊備份，避免單一快照遺失。
3. 匯出前會重新解析並檢查球員狀態、年度對話、時間軸與年度流程檢查點。
4. 若生涯已有內容但年度對話快照為空，會取消匯出並顯示錯誤，不再下載不完整小檔案。
5. 匯出完成後會顯示實際檔案大小、年度區塊數及時間軸年數，方便立即核對。
6. 延長瀏覽器下載網址保留時間，避免大型 JSON 尚未完成接手就被提早撤銷。
7. 匯入時若主要年度 HTML 缺失，會自動使用逐區塊備份復原。
8. 繼續相容 v0.20.0 與較早的 JSON 存檔。

建議測試
匯出後先查看修改器顯示的 KB、年度區塊與時間軸數量；再用同一檔案匯入，確認畫面回到匯出時的位置並可繼續操作。
