# 棒球生涯模擬器 ⚾

這是一款純文字的棒球生涯養成遊戲。玩家可輸入出生年份並從國小、國中、高中或大學開始，經歷選秀、旅外、國際賽，直到引退，體驗每一次擲骰與選擇帶來的棒球人生。

fork from [leoggcat/yakyulife](https://github.com/leoggcat/yakyulife)

## 遊戲特色
* **多層級聯賽**：完整模擬高中、大學、業餘成棒、中職、日職與大聯盟的升降級與合約交涉。
* **跨年代生涯**：最低可輸入 1972 年出生，起始年份隨就讀階段換算；國際賽採 1990～2026 歷史表與之後的固定循環。
* **隱藏屬性系統**：包含天才、鐵人等豐富的隱藏特質。
* **人生隨機事件**：感情選擇、傷病危機、公關事件與國際賽徵召，球場外的每一個決定都會影響生涯走向。
* **可維護的國際賽資料庫**：`database/國際賽事資料庫.xlsx` 可直接用 Excel 調整 1980～2079 賽程與各階段徵召門檻；每次開新生涯或匯入存檔都會重新讀取。
* **細緻的數據運算**：依照球探量表 (20-80) 進行能力養成，並根據不同守備位置與角色定位給予專屬評價。
* **可調整開局與大會平衡**：建立球員時可設定起始潛力倍率；F10 可獨立調整學生／業餘大會成績倍率，不會連動國際賽或職業球季。
* **完整二刀流生涯**：簽約與國際賽可逐次選擇投手、打者或二刀流身分；投打兩套球季、國際賽與生涯累積數據都會完整保留。
* **完整 JSON 與安全備份**：年度中途的訓練分配也能保存與重建；可設定每隔數年在年度開始詢問匯出，或自動保留最近的瀏覽器安全備份。
