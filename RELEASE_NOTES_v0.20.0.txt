YaKyoLife 離線生涯擴充版 v0.22.0

本版新增兩項獨立的平衡調整：

一、學生／業餘大會成績倍率
- 位於 F10 修改器「獎項／國際賽／年度成績浮動」。
- 範圍 0～100，預設 1.00。
- 只影響國小、國中、高中、大學與台灣業餘成棒的年度／地區大會。
- 1.00 與 v0.19.0 原始計算相同。
- 不影響國際賽、WBC、十二強、職業聯賽、二軍或小聯盟。

二、起始潛力倍率
- 位於新生涯畫面、出生年份下方。
- 範圍 0.10～3.00，預設 1.00，每次可調 0.05。
- 建立角色時將每一項原始潛力乘上倍率並四捨五入，最高 150。
- 只套用一次，不增加目前能力，也不會在往後年度重複乘算。
- 倍率會寫入完整 JSON 快照；舊存檔則安全視為 1.00。

相容性
- 可直接匯入 v0.19.0 的完整 JSON 存檔。
- 舊生涯的既有能力與潛力不會被重新計算。
