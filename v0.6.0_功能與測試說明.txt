YaKyoLife 離線生涯擴充版 v0.6.0

這一版以 v0.5.1 為底，並整合 v0.5.2 的健康修改器。

一、打工與現金
- 從國一開始，每年季初選擇一次生活／打工安排。
- 國中、高中、大學、業餘成棒、職業球員的選項與收入不同。
- 高強度工作會直接以少訓練骰、特訓加價、傷病修正或小幅球季代價呈現。
- 「生涯總收入」與「現金」分開；消費不會倒扣生涯薪資紀錄。

二、付費特訓
- 每年最多選三項能力，總點數上限依階段而定。
- 單點價格會依階段、能力高低與能力種類動態重算。
- 不能把目前能力練過潛力上限。
- 高三起可以嘗試每年一次的潛力突破；失敗只扣費用。
- 沒有新增通用疲勞值，也沒有疲勞條。

三、多人感情
- 16 歲起開放，學生階段與職業／20 歲後使用不同人物池。
- 可同時認識多人，每人獨立保存好感、身分、相識年與狀態。
- 每年三次互動；有免費陪伴、吃飯電影、禮物、旅行與認識其他人。
- 好感達門檻後會進入告白、公開、求婚與結婚流程。
- 已有正式伴侶時，新認識的人不會自動取代伴侶。

四、選秀與旅外
- 日本高中／大學畢業生可參加日職選秀。
- 選秀層級包括第一指名、前段支配下、後段支配下與育成指名。
- 台灣畢業生走日職入團測試或國際自由球員洽談。
- 旅日與旅美道路在畢業頁面會保留顯示；未達門檻時會告訴你目前能力與需求。

五、F10 修改器
- 球員／能力：姓名、年齡、背號、生涯收入、現金、能力、潛力、本年打工與特訓收支。
- 健康／傷病：實際受傷率、0～95% 覆寫、永不受傷、完全康復、體質與復健紀錄。
- 投手手肘：負荷、上限、TJ／危機次數、投球方式、當下歸零、鎖定零與完全修復。
- 人物關係：可修改每位已認識人物的好感。
- 存檔：本機儲存／讀取與 JSON 匯出／匯入。

六、舊存檔
- v0.5.1 與 v0.5.2 JSON 可直接匯入。
- 舊伴侶會自動轉成多人關係資料庫的人物。
- 缺少的現金、打工、特訓與健康欄位會自動補齊。

七、建議測試順序
1. 開新檔時選國中或高中，確認季初出現年度生活安排。
2. 分配普通訓練骰後，確認進入付費特訓。
3. 16 歲後確認每年三次感情互動，並可新增第二位人物。
4. 用日本高中檔打到畢業，確認出現日職選秀。
5. 按 F10 檢查現金、人物關係、健康及 JSON 匯出匯入。

若要回報問題，請一併說明：起始階段、國家、年齡／年度、球員類型、點選項後的畫面，以及是否由舊 JSON 匯入。
